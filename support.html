第一次使用

舞台换线单支持 iOS 17 及以上版本的 iPhone。打开「内置演示」，预览计划，逐盒核对并确认现场放行，再逐条开始和记录步骤。建立正式项目时，先配置舞台盒，再手动填写 A/B 接线表或导入 CSV。「工作区工具」可以导出 CSV 模板，「项目操作」可以导出 A/B 接线 CSV。

中断或现场不符

暂停实物操作，核对盒标、线标、端口和空口。按实际情况更新口位，标记仍在暂置点的线，并逐盒确认后重算。如果不能确认实物状态，可中止执行并保留历史。由现场负责人按设备流程处理静音、幻象供电和线路检查。

免费次数与恢复购买

每次安装可免费开始两次正式换线。正式执行单成功生成后使用一次额度。演示可反复练习，复核、续跑和复原沿用原有执行。要买断或恢复此前的购买，联网后在首页打开「工作区工具 → 终身解锁」。恢复时使用购买时的 Apple 账户。解锁验证成功后可离线执行换线。

备份与报告

从「工作区工具」把完整备份保存到「文件」。恢复会整体替换当前工作区。需要保留当前项目和记录时，请先导出备份。如果有换线正在执行，完成或中止后再恢复工作区。在 PDF 预览页使用系统分享功能发送报告或存入「文件」。

Contact support

Email xujorjor@hotmail.com for support. The operator is 立云 许.

Include the app version, iPhone model, iOS version, steps to reproduce, and any message shown on screen. Remove event, client, and personnel details from screenshots or files before sending them. If you can reproduce the issue in the Training Demo, include the demo steps.

Get started

Stage Repatch supports iPhone with iOS 17 or later. Open the Training Demo and preview the plan. Check each stagebox and confirm clearance to repatch, then start and record each step. For your own project, configure the stageboxes before entering the A/B patches or importing a CSV. Use Workspace Tools to export the CSV template and Project Actions to export an A/B wiring CSV.

After an interruption or a mismatch

Pause physical work and check the box labels, cable IDs, occupied ports, and empty ports. Update the patch you observe, identify any cables still set aside, and confirm each stagebox before recalculating. If you cannot verify the physical state, abort the run to preserve its history. The stage lead handles muting, phantom power, and line checks according to the equipment procedure.

Free runs and restoring purchases

Each installation includes two free live runs. A free run is used when a new live run is saved successfully. You can repeat the demo at any time. The same run covers field checks, resuming, and rollback. To buy or restore, go online and open Workspace Tools → Lifetime Unlock. Restore with the Apple Account you used to buy. Once the unlock is verified, you can run changeovers offline.

Backups and reports

Save a full backup to Files from Workspace Tools. Restoring replaces the entire current workspace. Export a backup first if you want to keep your current projects and records. Finish or abort an active run before restoring the workspace. Use the system share sheet from the PDF preview to send a report or save it to Files.

サポート

お問い合わせ

サポート窓口は xujorjor@hotmail.com です。運営者は 立云 许です。

お問い合わせの際は、アプリのバージョン、iPhone の機種、iOS のバージョン、再現手順、画面に表示されたメッセージをお知らせください。スクリーンショットやファイルを送る場合は、公演、取引先、スタッフに関する情報を削除してください。内蔵デモで再現できる場合は、その手順をお知らせください。

使い始める

Stage Repatch は iOS 17 以降を搭載した iPhone に対応しています。まず内蔵デモで計画を開き、各ステージボックスと作業許可を確認してから、手順を一つずつ開始・記録してください。実際のプロジェクトでは、ステージボックスを設定してから A/B 配線表を入力するか、CSV を読み込みます。作業領域のツールから CSV テンプレートを、プロジェクトのメニューから A/B 配線 CSV を書き出せます。

中断した場合や計画と配線が異なる場合

配線作業をいったん止め、ボックスのラベル、ケーブル ID、使用中のポート、空きポートを確認してください。実際の配線を入力し、一時的に外したままのケーブルに印を付けます。各ステージボックスを確認したうえで手順を再計算してください。現物を確認できない場合は、作業を中止して履歴を残せます。ミュート、ファンタム電源、ラインチェックは現場の責任者が機器の手順に従って行ってください。

無料利用枠と購入の復元

インストールごとに、実際の配線替えを 2 回まで無料で開始できます。新しい実作業が正常に保存されると 1 回分を消費します。デモは何度でも試せます。現場確認、作業の再開、元の配線に戻す操作は同じ作業に含まれます。買い切りの購入や復元を行うには、インターネットに接続してホーム画面の作業領域ツールからロック解除画面を開きます。復元には購入時と同じ Apple Account をお使いください。ロック解除を確認した後は、オフラインで配線替えができます。

バックアップとレポート

作業領域のツールから「ファイル」にバックアップを保存できます。復元すると現在の作業領域全体が置き換わるため、現在のプロジェクトや記録を残す場合は先にバックアップを書き出してください。実行中の作業は、作業領域を復元する前に完了または中止してください。PDF はプレビュー画面の共有メニューから送信するか、「ファイル」に保存できます。
